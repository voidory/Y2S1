# CM2021 priming sheet: the reactions worth having in your head tomorrow

Order = most likely to be asked first. "Asked" = appeared in 2023/24, 2024/25 or 2025/26. Everything is from the app's reaction list (checked against the Kinjo decks where the slides print it). Read it, cover it, write it out once.

## 1. Phosphorus (biggest gap: a 10-mark scheme in 2025/26, phosphorus in all three years)
Rock to P₄ to everything: **P₄ is the hub.**

| Step | Equation | Note |
|---|---|---|
| Make P₄ (asked) | 2Ca₃(PO₄)₂ + 6SiO₂ + 10C → P₄ + 6CaSiO₃ + 10CO | about 1700 K, sand and coke; P₄ condensed under water |
| + F₂ (asked) | P₄ + 10F₂ → 4PF₅ | |
| + limited Cl₂ | P₄ + 6Cl₂ → 4PCl₃ | |
| PCl₃ + water (asked) | PCl₃ + 3H₂O → H₃PO₃ + 3HCl | |
| + limited O₂ | P₄ + 3O₂ → P₄O₆ | |
| + excess O₂ | P₄O₆ + 2O₂ → P₄O₁₀ | |
| P₄O₆ + water | P₄O₆ + 6H₂O → 4H₃PO₃ | |
| P₄O₁₀ + water | P₄O₁₀ + 6H₂O → 4H₃PO₄ | |
| P₄O₁₀ dehydrates an amide | 6PhCONH₂ + P₄O₁₀ → 6PhCN + 4H₃PO₄ | |

Hook: limited oxidant stops at P(III) (PCl₃, P₄O₆, H₃PO₃); excess goes to P(V) (PF₅, P₄O₁₀, H₃PO₄).

## 2. Nitrogen oxides, nitric acid, aqua regia
| Reaction | Equation |
|---|---|
| Aqua regia (asked twice) | HNO₃ + 3HCl → NOCl + Cl₂ + 2H₂O ; then Au + NOCl + Cl₂ + HCl → HAuCl₄ + NO |
| ClO₂ (asked) | 2NaClO₃ + SO₂ + H₂SO₄ → 2ClO₂ + 2NaHSO₄ |
| Conc. HNO₃ oxidises (NO₂ is the N product) | Cu + 4HNO₃ → Cu(NO₃)₂ + 2H₂O + 2NO₂ ; P₄ + 20HNO₃ → 4H₃PO₄ + 20NO₂ + 4H₂O |
| NO to NO₂ | 2NO + O₂ → 2NO₂ |

Check the first aqua regia step balances (the slide prints H₂O, not 2H₂O). Gold ends as [AuCl₄]⁻.

## 3. The nitrogen chain (you know most of this; one line each)
- Haber: N₂ + 3H₂ → 2NH₃ (Fe₃O₄, about 500 °C, 500 atm)
- Ostwald: 4NH₃ + 5O₂ → 4NO + 6H₂O (Pt, about 1300 K) ; 2NO + O₂ → 2NO₂ ; 3NO₂ + H₂O → 2HNO₃ + NO
- Olin–Raschig (hydrazine): 2NH₃ + NaOCl → N₂H₄ + NaCl + H₂O (via chloramine NH₂Cl)
- Wislicenus (asked): 2Na + 2NH₃ → 2NaNH₂ + H₂ ; 2NaNH₂ + N₂O → NaN₃ + NaOH + NH₃
- Azide decomposes: 2NaN₃ → 2Na + 3N₂

## 4. Group 1 and oxygen (you know the trend; the water step is the one people drop)
- Li gives the oxide, Na the peroxide, K the superoxide: 4Li + O₂ → 2Li₂O ; 2Na + O₂ → Na₂O₂ ; K + O₂ → KO₂
- Peroxide + water: Na₂O₂ + 2H₂O → 2NaOH + H₂O₂
- Superoxide + water: 2KO₂ + 2H₂O → 2KOH + H₂O₂ + O₂
- Superoxide + CO₂: 4KO₂ + 2CO₂ → 2K₂CO₃ + 3O₂
- Li alone takes N₂: 6Li + N₂ → 2Li₃N
- Metal + water: 2Na + 2H₂O → 2NaOH + H₂

## 5. Nuclear equations: balance, do not memorise
Mass number A and atomic number Z each balance. n is A 1, Z 0. α is A 4, Z 2. β⁻ adds 1 to Z (n → p + e⁻). Read the element from Z.
- ²²Ne + α, then lose n → ²⁵Mg (A: 22 + 4 − 1 = 25; Z: 10 + 2 = 12). Asked 2024/25.
- ²³⁸U + n, then two β⁻ → ²³⁹Pu (Z: 92 → 94). Asked 2025/26.
- ¹⁴N + n → T + ¹²C. ⁹Be + α → n + ¹²C.

## 6. Three rules that give you the rest (use them if you blank on a reaction)
1. **Covalent p-block halides hydrolyse to the oxoacid or oxide plus HX**: PCl₃ → H₃PO₃ + 3HCl; BCl₃ → B(OH)₃ + 3HCl; SiCl₄ → SiO₂ + 4HCl. Exceptions: SF₆ does nothing (kinetically inert, ΔG° = −221 kJ/mol); SiF₄ keeps its fluoride as [SiF₆]²⁻.
2. **Basic anions take H⁺ from water**: H⁻ gives H₂ (CaH₂ + 2H₂O → Ca(OH)₂ + 2H₂); O²⁻ gives OH⁻; O₂²⁻ gives H₂O₂; O₂⁻ gives H₂O₂ and O₂.
3. **Burn it in O₂: small cation, normal oxide; big cation, peroxide or superoxide.** Mg gives MgO but Ba gives BaO₂.
